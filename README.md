# 🍽️ Интерактивное меню кафе «Уют»

Адаптивный одностраничный сайт-меню с возможностью заказа блюд онлайн. Создан с помощью вайб-кодинга — генерации веб-приложений через AI-инструменты.

## 🎯 Функционал

- **Тёмная и светлая тема** — переключение оформления в один клик
- **Блюдо дня** — специальное предложение со скидкой 15%
- **Корзина заказов** — добавление блюд, подсчёт итоговой суммы, оформление заказа
- **Категории меню**:
  - Закуски
  - Супы
  - Горячее
  - Салаты
  - Десерты
- **Адаптивный дизайн** — корректное отображение на десктопе и мобильных устройствах
- **Контакты** — адрес, часы работы, телефон, email

## 🛠 Технологии

- HTML5
- CSS3 (Flexbox, Grid, переменные для тем)
- JavaScript (vanilla, без библиотек)

## 🚀 Как запустить

1. Скачайте файлы репозитория
2. Откройте `index.html` в браузере
