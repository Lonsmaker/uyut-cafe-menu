# uyut-cafe-menu

«Интерактивное меню кафе с корзиной заказов» — пет‑проект для демонстрации навыков верстки и базовой логики на чистом JavaScript.

## 🖥 Демо

Посмотреть проект в работе можно по ссылке:  
👉 [uyut-cafe-menu](https://lonsmaker.github.io/uyut-cafe-menu/)

## 🛠 Стек технологий

- HTML5
- CSS3 (Flexbox/Grid)
- JavaScript (Vanilla)

## 📋 Функционал

В проекте реализованы следующие возможности:

- **Просмотр меню с категориями** — блюда разделены по типам (салаты, супы, горячее и т.д.).
- **Добавление в корзину** — при клике на кнопку «В корзину» товар попадает в список заказа.
- **Подсчёт итоговой суммы** — корзина автоматически пересчитывает общую стоимость выбранных позиций.
- **Очистка корзины** — отдельная кнопка для сброса текущего заказа.

## 🚀 Как запустить локально

Чтобы запустить проект на своём компьютере:

1. Клонируйте репозиторий:  
   `git clone https://github.com/Lonsmaker/uyut-cafe-menu.git`
2. Перейдите в папку проекта:  
   `cd uyut-cafe-menu`
3. Откройте файл `index.html` в любом браузере.  
   *Никакие дополнительные зависимости или сервер не требуются.*
